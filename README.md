# 🛒 Shopify Financial Dashboard — Automated P&L Pipeline
## The Problem
Most Online store owners spend 6–8 hours every month manually exporting data, building spreadsheets, and calculating margins, time that should go toward growing the business. One wrong formula means a wrong financial decision.
## The Solution
Automated P&L Report in less 5then 15 mins for Raw data given in Excel Format.

## Key Metrics Generated
It Generates the following Matrics:
- Gross Revenue
- Net Margin
- Refunded Rate
- Total COGS
- Net Revenue
- Net Profit
- Net Margin

## Tech Stack
- Python: Main Coding Language to build a pipeline
- pandas: To extract and format raw Data
- openpyxl: to put an image in an Excel file and give us the report in Excel format
- matplotlib: for a graph to draw

## How to Use
- Step 1: Open Text Editor (VS Code/Google Colab) 
- Step 2: pip install -r requirements.txt
- Step 3: Copy & paste main.py and Run the code
- Step 4: Get you excel File in the same folder and open it
- Step 5: Done, Make your Financial Decision

## Business Impact
8 hr of Manual work done in just 15 mins
